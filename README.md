# Lumina Tech

Landing Page desenvolvida para a avaliação N2.

## Sobre o projeto

A Lumina Tech é uma empresa fictícia especializada em painéis solares inteligentes e sistemas de monitoramento de energia via aplicativo.

O objetivo do projeto é criar uma landing page moderna, responsiva e acessível, focada em conversão de clientes e apresentação da marca.


## Funcionalidades

- Menu de navegação fixa
- Hero section
- Seção de benefícios
- Depoimentos
- Responsividade para dispositivos móveis
- Formulário de contato
- Design moderno

## Como executar o projeto

1. Baixe os arquivos do projeto
2. Abra o arquivo `index.html` no navegador

## Responsividade

O projeto foi desenvolvido para:
- Desktop
- Tablet
- Smartphones
